## 🚀 Featured Projects

### [Master's Thesis — Heterogeneous Hybrid ANN Index](https://github.com/ruban-ai/polygon-ann-multi-index)
A hybrid approximate-nearest-neighbor index that routes queries dynamically across CPU/GPU (HNSW, GPU-accelerated nested LSH, and exact search), replacing high-dimensional vectors with MinHash signatures + weighted Jaccard re-ranking.
**Results:** 🔻 **70% memory reduction** at equivalent recall · ⚡ **3× QPS improvement** over baseline at million-vector scale.
**Tech:** Python · FAISS · HNSW · MinHash · LSH · GPU · Linux HPC

### [ML-Based Polygon Embeddings for Similarity Search](https://github.com/ruban-ai/polygon-ann-ml-embeddings)
Learned polygon embeddings via contrastive training, with ANN indexing (cosine & weighted Jaccard) for semantically meaningful retrieval at scale. *Targeting SIGSpatial 2026.*
**Tech:** Python · PyTorch · FAISS · HNSW · Contrastive Learning

### [Distributed Polygon Embeddings](https://github.com/ruban-ai/distributed-polygon-embeddings)
Distributed training of polygon embedding models on GPU/HPC clusters using Distributed Data Parallel.
**Tech:** PyTorch · DDP · CUDA · HPC · GPU Computing

### [AI Accessibility Analyzer](https://github.com/ruban-ai/deep-learning-accessibility-audit)
Multimodal system that detects accessibility issues in digital content (images, alt-text, tables, headings) using deep learning and LLM-based reasoning, with precision/recall evaluation. *Targeting AAAI 2026.*
**Tech:** Python · Deep Learning · Multimodal AI · LLMs · Computer Vision

### [Emotion Detection in Sales Calls](https://github.com/ruban-ai/emotion-detection-sales-calls)
Real-time emotion classification from video — a frame-extraction pipeline (1,000+ frames/session) feeding a CNN multi-class classifier (engagement, frustration, neutrality).
**Tech:** PyTorch · OpenCV · CNNs
